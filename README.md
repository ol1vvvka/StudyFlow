# StudyFlow

Личное учебное пространство: предметы, материалы, заметки и календарь в одном приложении. Работает локально на Android и Windows; подключение Яндекс ID необязательно.

Проект находится в разработке. Публичного релиза пока нет.

## Возможности

- **Предметы:** название, преподаватель, описание, цвет и иконка.
- **Материалы:** файлы PDF/DOCX, фото, видео, снимки с камеры и ссылки. Поиск и открытие во внешнем приложении.
- **Заметки:** текстовые записи с автосохранением, поиском и привязкой к предмету.
- **Календарь:** год, месяц, неделя и день. События, мероприятия, задачи и встречи с началом и окончанием, вариант «Весь день», редактирование и удаление.
- **Темы:** светлая и тёмная, молочный/угольный фон и лаймовый акцент, шрифт Nunito.
- **Яндекс:** вход через OAuth с PKCE и резервное копирование материалов и заметок в папку приложения на Диске. Для работы нужен собственный ClientID.

Календарь хранится на устройстве. Напоминания, повторения, карточки для запоминания и полноценная синхронизация между устройствами ещё не реализованы. Задачи календаря пока самостоятельны и не связаны с задачами на странице предмета.

## Сборка

Нужны .NET 10, инструменты .NET MAUI и Android SDK. Для Windows — Windows SDK; удобно использовать Visual Studio с установленной нагрузкой .NET MAUI.

```powershell
dotnet workload restore StudyFlow/StudyFlow.csproj
dotnet restore StudyFlow/StudyFlow.csproj
dotnet build StudyFlow/StudyFlow.csproj -f net10.0-windows10.0.19041.0
dotnet build StudyFlow/StudyFlow.csproj -f net10.0-android
```

Для запуска откройте `StudyFlow.slnx`, выберите Windows Machine или подключённое Android-устройство и запустите проект. iOS и Mac Catalyst указаны как будущие целевые платформы; их работа пока не проверена.

### Настройка Яндекса

Без локального конфига сборка использует `YandexConfig.example.cs` с пустым ClientID. Остальная функциональность работает без авторизации.

Для входа скопируйте `StudyFlow/Services/Yandex/YandexConfig.example.cs` в `YandexConfig.cs` рядом с ним и заполните `ClientId`. Локальный файл исключён из Git. Client secret в мобильное приложение не добавляется. Токены пользователя хранятся в `SecureStorage`, а не в исходниках.

Регистрация приложения и адреса возврата описаны в [инструкции Яндекса](docs/YANDEX.md).

### Проверки календаря

```powershell
dotnet run --project tests/StudyFlow.Calendar.Checks
```

Проверки используют отдельную временную SQLite-базу. Проверяются границы периодов, записи через полночь и на целые дни, пересечения, сохранение, повторное чтение, изменение и удаление.

Последняя проверка исходников: Windows и Android собираются без ошибок и предупреждений; пройдена 21 проверка календаря. Реальный вход и отправка на Яндекс Диск пока не проверены — ClientID не настроен. Это не заменяет проверку интерфейса на устройствах.

## Структура

```text
StudyFlow/
  Models/       модели предметов, материалов, заметок и календаря
  Data/         SQLite-репозитории и миграции
  Services/     файлы, авторизация и резервное копирование
  PageModels/   состояние и команды экранов
  Pages/        страницы и элементы интерфейса
  Resources/    темы, локализация, шрифты и ресурсы
tests/          проверки календаря
docs/           концепция и инструкции
```
