# Бэклог StudyFlow

## Дизайн — в работе

- Согласованная палитра от 03.11.2026: мягкий лайм `#DBE64C`, ночной синий `#001F3F`, молочный `#F6F7ED`; дополнительные зелёные `#00804C` / `#74C365` и синий `#1E488F`. Актуальные роли — в `DESIGN.md`.
- Компактные карточки с крупными значениями, мягкими градиентами и небольшими подсвеченными акцентами. Светлая и тёмная темы должны сохранять общую композицию.
- Анимированный splash с мягким светящимся кругом в лаймовой гамме; временно только название StudyFlow.
- Отдельно разработать логотип и иконку приложения; текущую иконку пока не считать финальной.

## Учебные трекеры — запланировано

- TRACK-01: тепловая карта занятий по дням; лаймовая интенсивность обозначает реальное время учёбы или количество завершённых повторений. В легенде явно указывать выбранную метрику.
- TRACK-02: кольца/полосы выполнения дневной и недельной цели, серия учебных дней, сравнение периодов.
- TRACK-03: прогресс по предметам и темам. Радарная диаграмма допустима только с сопоставимыми, объяснимыми шкалами, а не как декоративная оценка знаний.
- TRACK-04: карточки статистики с крупным числом, небольшим графиком и мягкой лаймовой подсветкой. В светлой теме сохранять контраст; данные не кодировать только цветом.
- Зависимости: история учебных действий, модуль повторения, таймер и задаваемые пользователем цели. До их реализации не показывать фиктивную статистику.

## Виджеты — запланировано после текущего дизайна

Под «виджетами» различать карточки внутри приложения и системные виджеты рабочего стола. Начать с Android, поддержку Windows/iOS рассмотреть отдельно.

### Варианты виджетов и карточек

| Задача | Содержание | Зависимости |
| --- | --- | --- |
| WIDGET-01 · Сегодня | Виджет рабочего стола: выбранная дата, ближайшие события, задачи на день; переход к нужной записи | Календарь |
| WIDGET-02 · Быстрая заметка | Открытие новой заметки одним нажатием; при выборе пользователя — последняя заметка | Заметки |
| WIDGET-03 · Карточки на повторение | Число карточек к повторению, кнопка запуска сессии | Модуль карточек |
| WIDGET-04 · Фокус | Таймер учебной сессии, оставшееся время, пауза и продолжение | Модуль таймера фокуса |
| WIDGET-05 · Учебная активность | Лаймовая тепловая карта, дни занятий подряд и прогресс по реальным данным | История учебных действий |
| WIDGET-06 · Карточки главной | Настраиваемые компактные блоки событий, заметок и повторений внутри приложения | Дизайн главной и соответствующие модули |
| WIDGET-07 · Активная сессия | Отдельно изучить активные уведомления/Live Activities для таймера; это не виджет рабочего стола | Таймер, ограничения платформ |

### Критерии для системных виджетов

- Поддержать компактный и расширенный размеры, обе темы, настройку отображаемого предмета.
- Обновлять данные после изменений в приложении и по расписанию с учётом ограничений Android, без постоянного фонового опроса.
- Кнопки и нажатия ведут в соответствующий экран; не показывать выдуманные значения ради оформления.
- Названия заметок и событий показывать только по выбору пользователя; отдельно проверить поведение на заблокированном устройстве.
- Проверить перезапуск телефона, отсутствие сети, изменение размера и переключение темы.
- Работать на локальных данных; не помещать токены и содержимое приватной конфигурации в разметку виджета.
