Выбранные пользователем цвета предметов и тегов — цвета данных, они не меняются при переключении темы. Цвет нового предмета по умолчанию — лаймовый.

## Композиция

Главная получает крупный заголовок и градиентную панель с переходом к календарю: молочно-зелёную в светлой теме, сине-зелёную в тёмной. Карточки — с мягкими скруглениями, тонкими границами и небольшими цветовыми маркерами предметов. Основные действия выделяются лаймом, второстепенные — нейтральной поверхностью.

Календарь месяца использует компактную сетку, год — адаптивные мини-календари. В режиме дня добавлена полоса дней недели; временная шкала оформлена тонкими горизонтальными линиями, события — прямоугольными карточками с небольшим скруглением и цветовой полосой. Название события расположено перед временем. Текущее время отмечается линией на момент построения экрана. Декоративное свечение не должно перекрывать текст или ухудшать читаемость дат.

## Стартовый экран

Фон, текст и интенсивность радиального свечения следуют сохранённой теме StudyFlow: молочный фон и ночной синий текст в светлой, ночной синий фон и молочный текст в тёмной. Тема читается из `app_theme` до создания стартовой страницы; тема устройства учитывается только при выборе «Системная». На Android 12+ выбранная тема системной заставки сохраняется через SplashScreen API для следующих холодных запусков. Значок системной заставки рисуется на прозрачной подложке: сплошной цветной квадрат (раньше ночной синий `#001F3F`) на светлом фоне больше не появляется.

Анимация длится примерно две секунды, смещает свечение и проявляет название. При отключённых системных анимациях переход выполняется сразу. На стартовой странице используется название StudyFlow; отдельный знак приложения описан ниже.

## Иконка приложения

Вокруг знака — мягкое радиальное лаймовое свечение, затухающее к ночному синему краю. Страницы получили градиенты из основной палитры и тонкие светлые кромки. Свечение реализовано векторным градиентом в фоновом слое, чтобы сохраняться при адаптивной обрезке Android.

Иконка «Открытое пространство»: две мягко скруглённые страницы на ночном синем фоне `#001F3F`. Левая страница — `#74C365`, правая — `#DBE64C`, короткая строка — `#F6F7ED`. Знак объединяет блокнот и рабочее пространство. Без букв и мелких деталей; фон и передний план разделены для адаптивной иконки Android. Исходники находятся в `StudyFlow/Resources/AppIcon/`.
