# Палитра StudyFlow

Текущее направление: молочный, угольный, нейтральные серые и лайм. Основа — референс с цветами C7FF2E / 0A0A0A / F7F7F1 / C9D0D6 / 6F7780. Nunito остаётся шрифтом приложения.

| Роль | Светлая тема | Тёмная тема |
| --- | --- | --- |
| Фон страницы | `#F7F7F1` | `#0A0A0A` |
| Карточки, панели | `#FFFFFF` | `#202020` |
| Основной текст | `#0A0A0A` | `#F7F7F1` |
| Вторичный текст | `#626970` | `#B0B7BE` |
| Разделители | `#C9D0D6` | `#3A3D40` |
| Основное действие | `#C7FF2E` | `#C7FF2E` |
| Текст на основном действии | `#0A0A0A` | `#0A0A0A` |
| Ссылки и активные иконки | `#476000` | `#C7FF2E` |
| Ошибка | `#B3261E` | `#FFB4AB` |

Ресурсы находятся в `StudyFlow/Resources/Styles/Colors.xaml`. `Primary` и `PrimaryDark` предназначены для контрастного акцентного текста. Для заливки кнопок используются `ActionBackground` и `ActionText`: лайм с чёрным текстом в обеих темах.

Выбранные пользователем цвета предметов и тегов — цвета данных, они не меняются при переключении темы. Цвет нового предмета по умолчанию — лаймовый.

На этом шаге меняется цветовая система. Формы и состояния контролов, размеры, отступы и иерархия шрифтов — следующий этап дизайна.
