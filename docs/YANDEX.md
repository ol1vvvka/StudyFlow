# Вход через Яндекс ID и хранение на Яндекс Диске

## Как это устроено

- Приложение входит через **Яндекс ID** по OAuth 2.0 с **PKCE**. Секрета приложения (client secret)
  в StudyFlow нет: его легко достать из APK, поэтому вместо него используется `code_verifier`.
- Файлы и заметки хранятся в **папке приложения** на Диске пользователя: `Приложения/StudyFlow`.
  Остальной Диск приложение не видит.
- Токены лежат в `SecureStorage` (на Android — в Android Keystore).
- Код: `StudyFlow/Services/Yandex/`, вход на Windows — `StudyFlow/Platforms/Windows/LoopbackAuthListener.cs`,
  приём ответа на Android — `StudyFlow/Platforms/Android/WebAuthenticationCallbackActivity.cs`.

## Резервная копия на Диске

После входа материалы и заметки сами отправляются на Диск (`StudyFlow/Services/CloudBackupService.cs`):

```
Приложения/StudyFlow/
├── <Пространство>/Материалы/<файл>      — PDF, фото, видео как есть
├── <Пространство>/Заметки/<Заголовок>.md — заметка в Markdown
└── Без предмета/Материалы/… и …/Заметки/… — записи вне пространств
```

- Каждое изменение помечается в базе (`SyncStatus`), отправка начинается через 3 секунды после последней правки,
  при открытии главной и по кнопке «Синхронизировать» в настройках.
- Переименование пространства или материала переносит файл на Диске, удаление — отправляет его в Корзину Диска.
- При совпадении имён выбирается «Имя (2).pdf».
- «Отправлять файлы только по Wi-Fi» в настройках придерживает файлы (заметки уходят всегда).
- Режим хранения файлов в настройках:
  - **Устройство и Диск** — локальная копия остаётся, на Диск уходит зеркало;
  - **Только Диск** — после успешной отправки файл удаляется с устройства и скачивается снова при открытии.
  Метаданные, текст заметок и календарь всегда остаются в локальной базе.
- Ссылки пока не отправляются — они поедут вместе с общим файлом данных на следующем шаге.
- Отправка идёт, пока приложение открыто; если его закрыть, остаток уйдёт при следующем запуске.
- При входе, если активны демо-данные, приложение предлагает удалить их перед синхронизацией.

## Регистрация приложения (делается один раз)

1. Войдите в свой аккаунт Яндекса и откройте <https://oauth.yandex.ru/client/new/id/>.
2. Тип приложения: **«Для авторизации пользователей»**. Его нельзя сменить после создания.
3. **Название:** `StudyFlow`. Так будет называться папка на Диске у пользователей: `Приложения/StudyFlow`.
   Можно загрузить иконку — её увидят на экране согласия.
4. **Платформы.**
   - **Веб-сервисы** → Redirect URI, добавьте оба адреса:
     - `ru.ol1vvvka.studyflow://auth` — для Android (и позже iOS);
     - `http://127.0.0.1:47563/` — для Windows.
   - **Android-приложение** (пригодится для официального Yandex LoginSDK, можно добавить сразу):
     - Android package name: `ru.ol1vvvka.studyflow`;
     - SHA256 Fingerprints — отпечаток своего ключа подписи, полученный локально через `keytool`.
       Для отладки используйте отладочный ключ своей среды разработки, для публикации — релизный.
5. **Доступы** (берём минимум — так люди охотнее соглашаются):
   - Яндекс ID: **«Доступ к логину, имени и фамилии, полу»** (`login:info`) и **«Доступ к портрету пользователя»** (`login:avatar`);
   - Яндекс Диск REST API: **«Доступ к папке приложения на Диске»** (`cloud_api:disk.app_folder`)
     и **«Доступ к информации о Диске»** (`cloud_api:disk.info`).
6. Сохраните приложение и скопируйте **ClientID** со страницы приложения.
   Скопируйте `StudyFlow/Services/Yandex/YandexConfig.example.cs` в `YandexConfig.cs` рядом с ним
   и заполните константу `ClientId`. Локальный `YandexConfig.cs` исключён из Git;
   без него проект собирается с безопасным примером и отключённым входом.
   ClientID не секретный. **Client secret никуда не копируйте** — он не нужен.

### Если форма не примет адрес

- Не принимает `ru.ol1vvvka.studyflow://auth` → для Android подключим официальный Yandex LoginSDK
  (он использует данные из раздела «Android-приложение»).
- Не принимает `http://127.0.0.1:47563/` → для Windows сделаем вход через код подтверждения:
  Redirect URI `https://oauth.yandex.ru/verification_code`, пользователь вставляет показанный код в приложение.

## Перед публикацией

- Пройдите **верификацию сервиса** на oauth.yandex.ru: без неё пользователи видят предупреждение на экране входа.
- Добавьте SHA256 релизного ключа подписи Android.
- Лимит на один файл на Диске: 1 ГБ без подписки Яндекс 360, 50 ГБ с подпиской.
